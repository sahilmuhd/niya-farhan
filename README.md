## // OVERVIEW

A custom single-page wedding invitation website built with plain HTML, CSS and JavaScript. It opens with a full-screen video intro and then reveals the invitation.

## // FEATURES

- Opening video intro with a tap hint
- Background wedding song with a music control
- Falling petal animation layer
- Scroll animations and smooth scrolling
- Event details with a live countdown timer
- Location section with map buttons

## // TECH_STACK

- HTML5, CSS3 and vanilla JavaScript in a single `index.html`
- GSAP and ScrollTrigger (loaded from cdnjs)
- Lenis smooth scroll (loaded from cdnjs)
- Google Fonts: Cormorant Garamond

## // GETTING_STARTED

```bash
# no build step - static site
open index.html
# or serve locally
python -m http.server 8000
```

## // PROJECT_STRUCTURE

```
index.html   # the whole site (markup, styles, scripts)
assets/      # images, intro video, wedding song
```
